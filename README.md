
Проект по распознаванию эмоций человека на фотографиях с использованием свёрточной нейронной сети (CNN), написанной на PyTorch. Модель обучена на датасете **FER2013** и классифицирует изображения лиц на 7 базовых эмоций.

Проект реализует полный пайплайн для задачи классификации эмоций:

- Автоматическая загрузка датасета FER2013 через `kagglehub`
- Предобработка и аугментация изображений (поворот, отражение, нормализация)
- Разделение train/val с сохранением стратификации классов
- Обучение кастомной CNN-архитектуры на PyTorch
- Использование планировщика learning rate (`ReduceLROnPlateau`)
- Сохранение лучшей модели по валидационной точности
- Оценка на тестовой выборке: `classification_report`, `confusion_matrix`, графики loss/accuracy

Модель распознаёт 7 классов:

| # | Класс | Эмоция |
|---|-------|--------|
| 0 | Angry | Злость |
| 1 | Disgust | Отвращение |
| 2 | Fear | Страх |
| 3 | Happy | Радость |
| 4 | Sad | Грусть |
| 5 | Surprise | Удивление |
| 6 | Neutral | Нейтральное |

Кастомная свёрточная сеть `EmotionCNN`:

```
Input (1 × 48 × 48)
│
├── Conv2d(1 → 32, 3×3) → BatchNorm → ReLU → MaxPool(2×2) → Dropout2d(0.25)
├── Conv2d(32 → 64, 3×3) → BatchNorm → ReLU → MaxPool(2×2) → Dropout2d(0.25)
├── Conv2d(64 → 128, 3×3) → BatchNorm → ReLU → MaxPool(2×2) → Dropout2d(0.25)
├── Conv2d(128 → 256, 3×3) → BatchNorm → ReLU → MaxPool(2×2) → Dropout2d(0.25)
│
├── Flatten (256 × 3 × 3)
├── Linear(2304 → 512) → ReLU → Dropout(0.5)
└── Linear(512 → 7)
```

**Особенности:**
- Batch Normalization после каждой свёртки для стабилизации обучения
- Dropout для борьбы с переобучением
- 4 свёрточных блока с прогрессивным увеличением каналов (32 → 64 → 128 → 256)

Датасет

Используется датасет [**FER2013**](https://www.kaggle.com/datasets/msambare/fer2013) с Kaggle:

- Изображения в градациях серого, размер **48×48**
- **Train:** ~28 709 изображений
- **Test:** ~7 178 изображений
- Датасет загружается автоматически через `kagglehub.dataset_download(...)`

**Разбиение:**
- Train: 80% от исходного train
- Validation: 20% от исходного train (стратифицированно по классам)
- Test: исходная тестовая выборка

**Аугментация (только для train):**
- `RandomHorizontalFlip`
- `RandomRotation(10°)`
- `Normalize(mean=0.5, std=0.5)`

## Обучение

**Гиперпараметры:**

| Параметр | Значение |
|----------|----------|
| Batch size | 64 |
| Optimizer | Adam (lr = 0.001) |
| Loss | CrossEntropyLoss |
| Epochs | 50 |
| Scheduler | ReduceLROnPlateau (patience=5, factor=0.5) |
| Seed | 42 |
| Device | CUDA / CPU |


## Оценка качества

После обучения на тестовой выборке выводятся:

- **Classification Report** — precision, recall, f1-score по каждому классу
- **Confusion Matrix** — тепловая карта ошибок модели
- **Loss / Accuracy curves** — графики обучения и валидации

## Результаты

После обучения на FER2013 модель показывает:

- **Test Accuracy:** ~60–65% (типично для FER2013 — датасет сложный, с шумными метками)
- Лучше всего распознаются: **Happy**, **Surprise**
- Хуже всего: **Disgust**, **Fear** (мало примеров в датасете)
